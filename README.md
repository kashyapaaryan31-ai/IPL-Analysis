# IPL-Analysis
Developed an interactive IPL 2008–2018 Excel dashboard using PivotTables, PivotCharts and slicers to analyze team performance, toss decisions, venues, title winners and player impact.
# 🏏 IPL Data Analysis Dashboard

An interactive **Excel-based IPL Data Analysis Dashboard** created using IPL match data from **2008–2018**.

## 📊 Project Overview

This project analyzes IPL match data to identify patterns and insights related to:

- Team performance
- Toss decisions and winning outcomes
- Venue statistics
- IPL title winners
- Player of the Match performance

## 🛠️ Tools & Techniques

- Microsoft Excel
- PivotTables
- PivotCharts
- Slicers
- Data Cleaning
- Data Analysis
- Data Visualization

## 🔍 Key Insights

- Fielding first accounted for a larger share of winning outcomes in the analyzed dashboard.
- Chennai Super Kings and Mumbai Indians recorded the highest number of IPL titles during 2008–2018.
- Wankhede Stadium and Eden Gardens hosted the highest number of matches among the top venues.
- Rashid Khan recorded the highest Player of the Match count in the displayed analysis.
